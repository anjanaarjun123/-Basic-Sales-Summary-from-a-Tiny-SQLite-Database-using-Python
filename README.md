#  Task 7 - Business Sales Summary using SQLite and Python

##  Task Overview
As part of my Data Analyst Internship, Task 7 involves analyzing a basic sales dataset stored in an SQLite database using SQL queries inside Python. The insights are then visualized with matplotlib and saved for reporting.For this I created a sample business dataset.


## What I Learned

- How to connect Python with an SQLite database using `sqlite3`
- Writing SQL queries inside Python to perform data aggregation
- Using `pandas` to manipulate SQL results
- Creating visualizations using `matplotlib`
- Exporting analysis results to CSV for reporting

---

##  Key SQL Concepts Used

- `GROUP BY`: Aggregating data by product, category, and salesperson
- `SUM()`: Calculating total quantity and revenue
- `ORDER BY`: Sorting results for ranking
- `ROUND()`: Formatting revenue values for readability
